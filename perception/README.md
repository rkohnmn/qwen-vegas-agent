# Perception

M1 provides word-level ASR behind an engine interface, a deterministic fixture engine, per-stream audio extraction, and energy-based silence refinement. `words.json` remains the shared contract; unaligned words have null times and cannot anchor cuts.

The corrected real-media run used faster-whisper `small` with VAD disabled, followed by WhisperX English alignment using `WAV2VEC2_ASR_BASE_960H`. It ran on CUDA with `int8_float16`, used 0.578 GB peak VRAM, and took 30.747 seconds for 120 seconds of audio (real-time factor 0.2562). ASR detected English at 0.9766 confidence; sentence-split alignment output mapped to all 210 transcript rows. The baseline planner emitted eight gap actions and no lexical cuts; the verifier reported 12 level-step and four pacing failures across 16 joins. No word-level ground truth, diarization, or LLM call was used.

The adapter maps WhisperX sentence-sized alignment results to raw ASR tokens by normalized text sequence, preserving raw segment indices. A mismatch keeps the raw words unaligned. The initial English smoke incorrectly paired sentence-split results by list index; regression tests cover the corrected mapping. Timing anchors still need human ground truth for an accuracy claim. The earlier Japanese run remains historical evidence: 298 timed subword rows did not match the word-level contract, so all 30 phrase-level tokens remained unaligned. No Japanese subword boundary was promoted to a word boundary. See [the evaluation record](../docs/EVALS.md).

The English checkpoint is stored in ignored `cache/asr_models/`; its exact size, checksum, source, and upstream-stated license are recorded in D-35. The Japanese and faster-whisper snapshot revisions, byte sizes, and missing local license files are recorded in D-32. The adapter disables VAD and diarization weight loading.
